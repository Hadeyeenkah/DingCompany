# Intercoastal Water LLC Portal

A secure investor and operations portal for Intercoastal Water LLC, an integrated power, water-supply, and sewage-treatment company. Signed-in users can manage their profile and review investment metrics, project value, estimated cost, progress, project information, and shared documents. Administrators can sign in with their own email and password, manage dashboard data, and upload PDF files for users.

## Run locally

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Security note

This is demo access only. Before deploying, replace all demo credentials, keep passwords and configuration in environment variables or a secure identity provider, enforce server-side authorization, and use a protected file-storage service for uploads.
